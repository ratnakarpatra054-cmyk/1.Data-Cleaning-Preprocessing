# 1.Data-Cleaning-Preprocessing
Netflix Data Cleaning & Preprocessing

## Project Overview
This project focuses on cleaning and preprocessing the Netflix Movies and TV Shows dataset using Python.

## Internship Details
- Organization: AusPify
- Project: Netflix Data Cleaning & Preprocessing

## Objectives
- Import Netflix dataset using Pandas.
- Identify missing values.
- Detect duplicate records.
- Handle missing values.
- Clean inconsistent formats.
- Transform date and categorical columns.
- Create a clean dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Project Workflow
1. Import the dataset.
2. Explore dataset information.
3. Identify missing values and duplicates.
4. Handle null values.
5. Transform date columns.
6. Extract duration features.
7. Save the cleaned dataset.
